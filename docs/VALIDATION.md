# Проверки и устройство сборки

## Проверенная версия игры

- SHA-256: `448f226f40cf4a2bf591818a8d2604ee1cb470aeb0ee2adc3f37a9e4aa448779`.
- Исходный EXE считывается, не заменяется. В исходниках проекта нет EXE или ресурсов игры.

## Извлечение

Iced 1.21.0 декодирует исполняемые секции. Декодирование синхронизируется на границах функций из x64 exception directory (`.pdata`). Подтверждение записей ограничено известным хешем и двумя наблюдаемыми шаблонами регистрации пары украинского и английского текста:

- обычные строки: вызов по RVA `0x29fc10`;
- длинные описания: вызов по RVA `0x215610`;
- предшествующие вызовы по RVA `0x4066d0` и `0x407970` с загрузкой адреса строки в `rdx`.

В установленной версии найдено 2 087 подтверждённых записей и 1 958 дополнительных кандидатов. Сканирование кандидатов не является доказательством полноты локализации. Кандидаты могут содержать ложные совпадения. Имена и отдельные строки требуют ручного подтверждения.

Сохраняются RIP-relative ссылки и абсолютные 64-битные ссылки из таблицы DIR64-релокаций. Прочие способы вычисления адресов не считаются автоматически доказанными. Записи со ссылками внутрь текста или совместным хранением окончания блокируются. Извлечённые по разным адресам одинаковые строки не объединяются; общая строка по одному адресу меняется во всех её использованиях.

## Сборка

Сборщик заново открывает оригинал с запретом параллельной записи, проверяет SHA-256 и повторяет извлечение. Импортированные смещения, флаги подтверждения и сведения о ссылках не используются как источник доверия. Ручное одобрение кандидата сохраняется отдельно.

Строгая сборка сохраняет размер и изменяет только диапазоны строк с терминаторами. Расширенная добавляет read-only секцию `.otrl`, не сдвигая существующие секции; обновляет заголовки и необходимые поля ссылок. DIR64-релокации остаются на прежних полях указателей. Результат проверяется чтением строк по новым адресам, разрешением изменённых ссылок и побайтовым сравнением разрешённых диапазонов с оригиналом. Повторная сборка тех же входных данных даёт те же байты EXE.

Запись выполняется во временный файл с flush и повторным чтением. При замене результата применяется атомарная файловая операция и уникальная резервная копия. Windows file identity защищает оригинал от записи через жёсткие и символические ссылки. Ошибка сохранения отчёта сообщается отдельно от успешного создания EXE.

## Автоматические проверки

Финальный прогон 19 ноября 2026: **42 проверки прошли, 0 ошибок**. Release-сборка компилируется без предупреждений. Проверка WPF отдельно пройдена на автономном `OstrivTranslate.exe`, а не только на отладочной сборке.

Исполняемый набор `tests/OstrivTranslate.Tests` проверяет:

- UTF-16, символы вне BMP, встроенный NUL, некорректные суррогатные пары, лимиты, форматирование и теги;
- неподтверждённые кандидаты, ссылки внутрь текста, общие окончания;
- CSV с несколькими языками, кавычками, переносами строк, конфликтами, повторами и ошибочными оригиналами;
- JSON, версии формата, резервные копии, точный и неоднозначный перенос переводов;
- защиту исходника, жёсткие ссылки, занятый результат и очистку временных файлов;
- реальное извлечение, строгую замену, перенос длинных описаний и подписей, несколько ссылок на строку, детерминированность, отчёт, подменённые смещения и доверительные флаги.

Отдельный WPF smoke-тест открывает реальную локализацию, меняет три языка интерфейса, два языка перевода, проверяет сохранность привязок и JSON, читает таблицы символов игровых шрифтов и сохраняет снимок редактора. Тестовая белорусская строка не имеет отсутствующих знаков в проверенных шрифтах.

## Проверка самой игры: границы результата

Тестовый EXE с новой секцией и семью удлинёнными строками был запущен из каталога игры. Подтверждены путь процесса, появление окна `Ostriv` и состояние процесса `Responding=True`. SHA-256 оригинала после проверки совпал с исходным. Временный тестовый процесс завершён, его EXE удалён из каталога игры.

**Не проверены:** визуальное отображение изменённых строк, переключение языка, новая игра, загрузка существующего сохранения, подсказки и размещение длинного текста во время игры. Доступ к снимку окна через Computer Use не был подтверждён до истечения срока ожидания. Наличие работающего процесса не доказывает корректность всех экранов или отсутствие отложенных сбоев.

Перед использованием законченного перевода вручную проверить:

1. Запущен именно созданный EXE; выбран украинский слот.
2. Короткая подпись с удлинением, название языка и длинное описание отображают перевод.
3. Открываются новая игра и существующее сохранение.
4. Подписи, подсказки и справка читаемы; текст не обрезан размерами элементов интерфейса.
5. Все используемые письменности отображаются корректно. Для RTL и сложного формирования глифов отдельная проверка обязательна: соответствующая доработка движка в редактор не включена.

Сборка для других хешей намеренно заблокирована до исследования соответствующей версии. Автоматическое применение старого профиля или обход механизмов Steam отсутствуют.
