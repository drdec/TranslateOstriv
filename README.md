# Ostriv Translation Studio

Настольный редактор локализации Ostriv для Windows x64. Интерфейс доступен на беларускай мове, русском и English. Украинский оригинал остаётся слева; справа редактируется выбранный язык перевода. В одном проекте можно хранить несколько языков.

Готовый **белорусский машинный черновик для вычитки**: [проект и инструкция](artifacts/translations/README.md). Заполнены все 2 087 подтверждённых записей; рядом есть CSV для импорта в ваш проект. Неподтверждённые кандидаты остаются отдельно.

## Запуск

Готовое приложение в рабочей папке: `artifacts/release/OstrivTranslate.exe`. Если вы получили ZIP выпуска, распакуйте его и запустите `OstrivTranslate.exe` рядом с этим README. Установка .NET не требуется. Не перемещайте EXE игры в каталог редактора: сначала откройте оригинал из его установленного каталога.

1. Нажмите **«Извлечь из EXE»**, выберите оригинальный `ostriv.exe` и добавьте язык перевода, например `be` / `Беларуская` или `pl` / `Polski`.
2. Выберите строку в таблице. Редактируйте перевод в правом нижнем поле. Пустой перевод оставляет оригинал.
   Для диапазона выберите первую строку и нажмите последнюю с **Shift**. **Ctrl + щелчок** добавляет или убирает отдельную строку; **Ctrl+A** в таблице выделяет все строки текущего поиска и фильтра. При множественном выборе поля одной записи скрываются, а общее поле подтверждения применяется ко всем выбранным кандидатам. Смешанная отметка означает, что подтверждена лишь часть: один щелчок подтвердит всех выбранных кандидатов. Снятие общей отметки отменяет их ручное подтверждение. Обычные подтверждённые записи и тексты переводов при этом не меняются.
3. Сохраняйте работу кнопкой **«Сохранить проект»** или `Ctrl+S`. `Ctrl+Shift+S` сохраняет под другим именем; `Ctrl+F` переводит фокус в поиск.
4. Для второго языка нажмите **«+ Язык»**. Переключение языка интерфейса не меняет язык перевода и не стирает правки.
5. Нажмите **«Собрать EXE…»** и **введите имя самостоятельно**, например `ostriv_bel.exe`. Рекомендуется сохранить его рядом с оригинальной игрой. Каждая сборка содержит один выбранный язык.
6. Нажмите **«Запустить сборку»**. В игре используйте **украинский языковой слот**; его отображаемое название можно перевести через запись `@locale@`. Новые языковые пункты в меню игры не добавляются.

## Два режима

- **Расширенный**, по умолчанию: длинные строки размещаются в новой секции `.otrl`, ссылки на них перенаправляются. Перемещение не сдвигает существующие секции. Сборщик проверяет изменённые диапазоны, адреса и результат записи. Короткие переводы заменяются на месте.
- **Строгий**: перевод не превышает исходный размер в UTF-16LE, свободные байты обнуляются, терминатор сохраняется. Размер EXE не меняется.

Лимит считается в **единицах UTF-16 и байтах**, не в визуальных буквах. Например, символ за пределами BMP занимает две единицы UTF-16. Поддержка Unicode не означает, что игровой шрифт имеет нужные знаки или что движок корректно соединяет арабские буквы. Редактор показывает отсутствующие знаки по каждому шрифту, но расположение текста и особенности письма нужно проверять в игре.

Параметры форматирования и распознанные теги должны сохраняться в прежней последовательности. Встроенный NUL и некорректные суррогатные пары запрещены. Переводы не обрезаются автоматически.

## Извлечение и полнота

Для проверенной сборки извлекаются **2 087 подтверждённых записей** по парам украинского и английского текста в коде, включая длинную справку. Дополнительное сканирование находит **1 958 кандидатов**: среди них имена и другие строки, но также возможны технический текст и ложные совпадения. Это не заявление о доказанной полноте перевода.

По умолчанию показаны подтверждённые записи. Для кандидатов выберите соответствующий фильтр. Их включение требует ручного подтверждения в карточке записи. Подтверждение означает проверку назначения текста пользователем, а не автоматическое доказательство его безопасности. Ссылки внутрь строки и пересекающиеся общие окончания блокируют автоматическую замену даже после подтверждения. Для удлинения обязательно наличие поддерживаемых ссылок.

Одинаковые строки по разным адресам представлены отдельно. Если несколько мест используют одну и ту же строку в памяти, изменение распространяется на все её ссылки; число ссылок и объединённый контекст показаны в карточке.

Поддерживаемый SHA-256 оригинала:

```text
448f226f40cf4a2bf591818a8d2604ee1cb470aeb0ee2adc3f37a9e4aa448779
```

Для других версий доступны поиск кандидатов и редактирование, но сборка заблокирована до создания проверенного профиля. Старые смещения не применяются к новому EXE.

## Проекты, CSV и обновления игры

Проект `*.ostriv.json` хранит хеш исходника, оригиналы, контексты, подтверждения кандидатов и переводы по языкам. Сохранение атомарное; при замене создаётся резервная копия с уникальным суффиксом `.bak-…`. Выходной EXE тоже сохраняется атомарно с резервной копией. Рядом с ним создаётся `*.exe.build.json` с хешами и перечнем изменений.

CSV использует UTF-8 с BOM и столбцы:

```csv
id,language,original,translation
```

Экспорт содержит все записи и языки проекта. Импорт показывает новые переводы, конфликты и неизвестные записи до применения. Конфликты по умолчанию не выбраны. Смещения, доверие к строке и ссылки из CSV не импортируются. Переводы, начинающиеся с `=`, сохраняются буквально: при открытии CSV в электронной таблице импортируйте столбец перевода как текст.

После обновления игры используйте **«Пересканировать / перенести»**. Совпадение оригинала и контекста предлагается автоматически; неоднозначные совпадения требуют выбора назначения. Несопоставленные записи видны в окне проверки. При смене версии результат сохраняется как новый проект, чтобы старые переводы оставались доступны. Новый профиль сборки не создаётся автоматически.

Оригинальные файлы игры не заменяются. Проверка идентичности файла учитывает жёсткие и символические ссылки Windows. Steam и его механизмы не изменяются. Отдельное имя EXE не гарантирует независимость от Steam или совместимость со следующей версией игры.

## Разработка и проверки

Требуются Windows x64, .NET SDK 10 и доступ к NuGet при первом восстановлении пакетов. Откройте `TranslateOstriv.slnx` в Visual Studio либо выполните:

```powershell
.\build.ps1 -Test -Publish
```

Для другого пути игры:

```powershell
.\build.ps1 -Test -GameExe 'D:\Games\Ostriv\ostriv.exe'
```

Тестовый проект — исполняемый набор проверок без отдельного тестового фреймворка. Без доступного EXE выполняются проверки JSON, CSV, Unicode и файловых операций; интеграционные проверки явно пропускаются.

```powershell
dotnet run --project tests/OstrivTranslate.Tests -- 'E:\steam\steamapps\common\Ostriv\ostriv.exe'
```

Приложение поддерживает воспроизводимую проверку WPF с выводом снимка окна, тестового проекта и результата в заданный каталог:

```powershell
.\artifacts\release\OstrivTranslate.exe --settings "$PWD\artifacts\smoke\settings.json" --smoke "$PWD\artifacts\smoke"
```

Эта проверка не запускает игру и не пишет в её каталог. Она использует путь из настроек или стандартный путь игры.

Структура исходников: `src/OstrivTranslate.Core` — извлечение, PE, проверки, проекты, CSV и сборка; `src/OstrivTranslate.App` — WPF, локализация и проверка шрифтов; `tests/OstrivTranslate.Tests` — проверки, в том числе на установленной игре. Техническое описание и границы проверок находятся в `docs/VALIDATION.md`.

Редактор не содержит файлов игры. Пакет выпуска включает редактор и лицензии зависимостей; тестовые копии EXE и извлечённые проекты в него не входят.
